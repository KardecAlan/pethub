## Introdução

Estas instruções ajudarão você a configurar e executar o projeto em sua máquina local para desenvolvimento e testes.

## Pré-requisitos

- Java 17 ou superior
- Gradle 7.0 ou superior
- Uma IDE como IntelliJ IDEA

## Instalação

1. Clone o repositório:
    ```sh
    git clone https://github.com/KardecAlan/pethub.git
    cd pethub
    ```

2. Construa o projeto usando Gradle:
    ```sh
    ./gradlew build
    ```
